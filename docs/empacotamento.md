# ZIP de entrega

Gere o arquivo a partir da versão final em main com `git archive --format=zip --output=../UrbanLink-Sprint4.zip main`. Use o repositório público indicado no README como evidência do histórico Git.

Confirme que o ZIP tem até 50 MB e contém README, package.json, lockfile, src, public e as configurações de Vite e TypeScript. Extraia em outra pasta e execute `npm ci` e `npm run build`.
